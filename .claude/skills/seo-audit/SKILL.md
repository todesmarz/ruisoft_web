# SEO監査 業務フロースキル

このスキルは **WebサイトのSEOを4カテゴリで監査し、改善案を生成する手順を定義** する。
「何を問題とするか」「修正優先度をどう付けるか」の価値判断基準は `seo-audit` エージェントの職種定義を参照すること。

---

## 🔄 全体フロー

```
Phase 1: 監査対象の把握
    ↓
Phase 2: 自動計測の実行（可能な場合）
    ↓
Phase 3: 4カテゴリ監査
    ↓
Phase 4: 問題点の統合と優先度付け
    ↓
Phase 5: SEO改善レポート生成
    ↓
Phase 6: （必要なら）修正実装
```

## 適用する標準・フレームワーク

| 標準 | 由来 | 適用 Phase | 役割 |
|---|---|---|---|
| **Google SEO Starter Guide** | Google | Phase 3 | SEO基礎の公式ガイド |
| **Google Search Quality Rater Guidelines** | Google | Phase 3 | 品質評価基準（E-E-A-T） |
| **E-E-A-T** | Google | Phase 3 | Experience/Expertise/Authoritativeness/Trustworthiness |
| **Core Web Vitals** | Google | Phase 3 | LCP/FID/CLSの3指標 |
| **Schema.org** | W3C | Phase 3 | 構造化データ標準 |
| **Lighthouse SEO** | Google | Phase 2 | SEOの自動計測 |
| **Search Console** | Google | Phase 2 | インデックス・検索パフォーマンス |
| **Bing Webmaster Guidelines** | Microsoft | Phase 3 | Bing向けSEO基準 |

## Phase 1: 監査対象の把握

以下を明確にする。

- **対象URL/サイト**：監査するWebサイト
- **対象ページ範囲**：トップページのみ or 全ページ or 特定ページ群
- **目標キーワード**：狙いたい検索キーワード（あれば）
- **競合サイト**：比較対象（あれば）
- **ビジネス目標**：アクセス増加・コンバージョン向上・ブランド認知等
- **監査深度**：全カテゴリ or 特定カテゴリに絞るか

---

## Phase 2: 自動計測の実行（可能な場合）

以下を活用し、自動取得可能なデータを収集する。

- **Google Search Console**：インデックス状況・検索クエリ・クリック数・表示回数・平均順位
- **Lighthouse SEO**：メタタグ・モバイルフレンドリー・HTTPS等の自動チェック
- **PageSpeed Insights**：Core Web Vitals実測値
- **Screaming Frog / site:検索**：クロール状況・インデックス数
- **被リンクツール**：Ahrefs / SEMrush / Search Console（被リンクレポート）

自動計測が不可能な場合は手動監査（Phase 3）で代替する。

## Phase 3: 4カテゴリ監査

### 3.1 技術SEO（約30ルール）

#### インデックス・クロール
- [ ] `robots.txt` が適切に設定されているか（重要ページがブロックされていないか）
- [ ] `sitemap.xml` が存在し、全重要ページが含まれているか
- [ ] `noindex` 指定が意図的か（検索に出したくないページのみ）
- [ ] `rel="canonical"` が重複ページに適切に設定されているか
- [ ] インデックス数がページ数と概ね一致するか（site:検索）
- [ ] クロールエラー（404/5xx）がないか

#### URL構造
- [ ] URLが簡潔・説明的か（`/products/seo-audit` 等）
- [ ] URLに不要なパラメータ・セッションIDがないか
- [ ] URLが小文字統一か
- [ ] 末尾スラッシュの有無が統一されているか
- [ ] www有無・HTTPSが正規化（リダイレクト）されているか

#### メタタグ
- [ ] `<title>` が30文字以内・説明的か（キーワード含む）
- [ ] `meta description` が120文字以内・要約的か
- [ ] ページ毎にtitle/descriptionがユニークか
- [ ] `meta robots` が適切か
- [ ] `lang` 属性が設定されているか

#### 構造化データ
- [ ] Schema.org構造化データが実装されているか（Article/Product/BreadcrumbList等）
- [ ] 構造化データがエラーなくValidか（Rich Results Test）
- [ ] パンくずリスト（BreadcrumbList）があるか

#### HTTPS・セキュリティ
- [ ] HTTPS化されているか
- [ ] HSTSヘッダが有効か
- [ ] 混在コンテンツ（HTTPリソース）がないか

#### サイト速度
- [ ] **LCP** < 2.5秒
- [ ] **FID** < 100ms
- [ ] **CLS** < 0.1
- [ ] 画像が最適化（WebP/AVIF・遅延読み込み）されているか
- [ ] CSS/JSが縮小・結合されているか

#### モバイル
- [ ] モバイルフレンドリーか（viewport設定・レスポンシブ）
- [ ] タップターゲットが44x44px以上か
- [ ] フォントサイズが16px以上（モバイル本文）か
- [ ] モバイルで読み込みが遅すぎないか

### 3.2 コンテンツSEO（約25ルール）

#### キーワード
- [ ] 目標キーワードがtitle・H1・本文に含まれているか
- [ ] キーワードの自然な出現か（詰め込みでない）
- [ ] 関連語（LSIキーワード）が含まれているか
- [ ] 検索意図（情報収集/取引/ナビゲーション）に合致する内容か

#### コンテンツ品質（E-E-A-T）
- [ ] **Experience**：実体験・一次情報が含まれるか
- [ ] **Expertise**：専門性が示されているか（著者情報・資格等）
- [ ] **Authoritativeness**：権威性があるか（引用・出典・被リンク）
- [ ] **Trustworthiness**：信頼性があるか（更新日・情報源明示）
- [ ] コンテンツが網羅的か（検索意図を満たす十分な情報量）
- [ ] コンテンツが新鮮か（更新日が最近・情報が古くない）
- [ ] 重複コンテンツでないか（他サイト/自サイト内）

#### 見出し構造
- [ ] H1が1つでページ主題を表しているか
- [ ] H2-H6が論理的階層になっているか
- [ ] 見出しが説明的か（キーワード含む）
- [ ] 見出し飛び（H2→H4等）がないか

#### 内部リンク
- [ ] 重要ページに内部リンクが集まっているか
- [ ] アンカーテキストが説明的か（「こちら」等の汎用語でない）
- [ ] 孤立ページ（被リンク0）がないか
- [ ] パンくずリストが実装されているか

#### 画像
- [ ] 画像に`alt`属性があるか（SEO+アクセシビリティ）
- [ ] 画像ファイル名が説明的か（`img123.jpg`でない）
- [ ] 画像が最適化されているか（サイズ・フォーマット）

### 3.3 ローカルSEO（約15ルール・対象の場合）

- [ ] Google Business Profileが登録・最適化されているか
- [ ] NAP（Name/Address/Phone）がサイト全体で一致しているか
- [ ] ローカル構造化データ（LocalBusiness）があるか
- [ ] ローカルキーワードが含まれているか（地域名）
- [ ] ローカル被リンク・引用（Citation）があるか
- [ ] レビュー収集・返信の仕組みがあるか
- [ ] 地図埋め込みがあるか

### 3.4 被リンク・権威性（約15ルール）

- [ ] 被リンク数・参照ドメイン数が競合比で十分か
- [ ] 被リンクの質（権威サイトからのリンク）が高いか
- [ ] 有害リンク（スパム・低品質）がないか
- [ ] アンカーテキストが自然な多様性か（過剰最適化でない）
- [ ] 内部リンク構造が適切か（PageRank分散）
- [ ] nofollowリンクの使い分けが適切か
- [ ] 被リンク獲得機会（共有されやすいコンテンツ）があるか

## Phase 4: 問題点の統合と優先度付け

検出した問題を以下の優先度で分類する。

| 優先度 | 定義 | 影響 |
|--------|------|------|
| **P0（Critical）** | インデックス除外・クロールエラー・重複コンテンツ | 検索に出ない |
| **P1（High）** | title/description不備・速度未達・モバイル非対応 | 順位低下 |
| **P2（Medium）** | 構造化データ未実装・内部リンク不備・コンテンツ薄 | 順位改善余地 |
| **P3（Low）** | 被リンク獲得・ローカルSEO・コンテンツ拡充 | 中長期改善 |

## Phase 6: 修正実装（必要な場合）

ユーザーが修正実装も依頼した場合、優先度順に修正する。

- P0から順に対応
- 各修正後に再監査で効果確認
- 修正内容をコミット単位でまとめる
- Search Consoleでインデックス更新をリクエスト

- [ ] 4カテゴリ（技術/コンテンツ/ローカル/被リンク）を確認した

---

## ⚠️ 注意事項

- SEO効果は即時出ない。1-3ヶ月単位で評価する
- ブラックハットSEO（キーワード詰め込み/隠しテキスト/リンク購入）は絶対に提案しない
- Google公式ガイドラインに準拠したホワイトハットSEOのみを提案する
- コンテンツ品質（E-E-A-T）は技術SEOより重要度が高い傾向にある
- 競合分析は相対評価で行い、絶対値だけで判断しない
