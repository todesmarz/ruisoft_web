## 障害対応

### 障害判定基準

| レベル | 定義 | 初動対応時間 |
|---|---|---|
| **P0（致命的）** | システム全体停止・データ損失リスク | 即時 |
| **P1（重大）** | 主要機能停止・代替手段なし | 15分以内 |
| **P2（中程度）** | 一部機能停止・代替手段あり | 1時間以内 |
| **P3（軽微）** | 性能劣化・見た目の問題 | 営業時間内 |

### 対応フロー

```mermaid
flowchart TD
    A[障害検知] --> B{障害レベル判定}
    B -->|P0/P1| C[即時エスカレーション]
    B -->|P2/P3| D[通常対応]
    C --> E[原因調査]
    D --> E
    E --> F[復旧対応]
    F --> G[事後対応]
    G --> H[障害報告書作成]
```
