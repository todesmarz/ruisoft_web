# Blog Mapper

`logs/` フォルダのMarkdownブログ記事を読み取り、トピック・テーマ別に分類した **markmap形式のMarkdownファイル** を生成するスキル。

---

## 実行前提

- カレントディレクトリ = ローカルリポジトリのルート
- 対象ファイル: `logs/**/*.md`
- 出力ファイル: `blog-map.md`（markmapで描画可能なMarkdown）

---

## 処理フロー

### Step 1: ファイル一覧の取得

```bash
find logs/ -name "*.md" | sort
```

ファイルが0件の場合はユーザーに確認してスキルを終了する。

### Step 2: 各記事のメタデータ抽出

各 `.md` ファイルを読み取り、以下を抽出する：

| 項目 | 抽出方法 |
|------|----------|
| **タイトル** | ファイル先頭の `# 見出し` or frontmatterの `title:` |
| **日付** | frontmatterの `date:` or ファイル名のYYYY-MM-DD部分 |
| **概要** | frontmatterの `description:` or 本文冒頭100〜150文字 |
| **タグ** | frontmatterの `tags:` があれば参照 |
| **ファイルパス** | 相対パス（リンク用） |

### Step 3: トピック・テーマ分類

抽出したメタデータをもとに、記事内容を読んでトピックを自動分類する。

**分類の考え方：**
- 記事の主題・キーワードからテーマを判断する
- 既存の `tags:` がある場合はそれを参考にする
- 1記事が複数テーマにまたがる場合は主テーマに配置し、補足として副テーマを記載する
- カテゴリ数の目安: 3〜8個（記事総数に応じて調整）
- カテゴリ名は日本語で、簡潔に（例：「技術・開発」「AI・機械学習」「キャリア・働き方」）

### Step 4: markmap Markdownの生成

以下のフォーマットで `blog-map.md` を生成する。

````markdown
---
markmap:
  colorFreezeLevel: 2
---

# ブログ記事マップ

## 📁 カテゴリA

### 記事タイトル1
- 📅 2024-01-15
- 💬 記事の概要（1〜2文）
- 🔗 [logs/2024-01-15-article.md](logs/2024-01-15-article.md)

### 記事タイトル2
- 📅 2024-02-10
- 💬 記事の概要（1〜2文）
- 🔗 [logs/2024-02-10-article.md](logs/2024-02-10-article.md)

## 📁 カテゴリB

### 記事タイトル3
...
````

**フォーマットルール：**
- ルートノード: `# ブログ記事マップ`
- カテゴリ: `##`（絵文字付き）
- 記事タイトル: `###`
- 各記事の子ノード: 日付・概要・ファイルリンクの3点
- 概要は1〜2文、最大80文字程度に収める
- ファイルパスは相対パスでリンク形式にする

### Step 5: ファイル出力と確認

1. `blog-map.md` をリポジトリルートに保存する
2. 処理結果をユーザーに報告する：

```
✅ blog-map.md を生成しました

- 対象記事数: XX件
- カテゴリ数: XX個
- カテゴリ一覧: カテゴリA / カテゴリB / ...

markmapで開くには：
  npx markmap-cli blog-map.md
  または VS Code の Markmap 拡張機能をご利用ください。
```

---

## 注意事項

- **frontmatterなし・タイトルなし**の記事はファイル名をタイトルとして使用する
- **内容が非常に短い**記事（100文字未満）は概要をそのまま全文記載する
- **記事数が多い場合**（50件以上）は処理に時間がかかる旨をユーザーに伝えてから開始する
- カテゴリ分類に迷う記事は `## 📁 その他` に配置する
