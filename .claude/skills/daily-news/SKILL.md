# AI ニュース スキル
 
前日のAI・テクノロジー・経済・地政学関連情報を複数カテゴリで収集し、以下の2つを出力する：
 
1. **HTMLファイル**（詳細版）：カテゴリ別タブ付きで `present_files` に提示
 
---
 
## 重要ルール
 
- **情報は前日分のみ**：今日から1日前（昨日）の情報に限定する
- **ファイル名**：`ai-news-YYYY-MM-DD.md`（前日の日付）
- **パス**：/logs/
- **バフェット・広瀬視点はAIによる解釈**：実際の発言ではなく、各氏の投資哲学・スタイルに基づいて生成AIが推論する。必ず「〜と見るだろう」「〜と分析するだろう」等の推量形で記述し、実際の発言との混同を避ける
 
---
 
## ワークフロー概要
 
```
1. 前日の情報を各カテゴリで収集する（Web検索）
2.ファクトチェックを行い情報の正確性を確保と補足情報が必要ならばweb検索をして収集する
3. HTMLファイル（詳細版）を生成 → present_files で提示
```
 
---
 
## Step 1: ニュース収集（Web検索）
 
**前日の日付**を検索クエリに必ず含める。今日が2026/3/29なら検索対象は2026/3/28。
 
### 収集カテゴリ一覧
 
| カテゴリ | 検索クエリ例 | 件数 |
|---------|------------|------|
| 📈 市場指標（株・債券・VIX） | `S&P500 VIX 日経平均 米10年債 YYYY-MM-DD 終値` | 数値のみ |
| 📊 景気指標 | `GDP CPI 雇用統計 PMI YYYY-MM-DD 発表` | 発表があれば |
| 🌏 地政学リスク | `war election geopolitics risk YYYY-MM-DD` | 主要3件まで |
| 🤖 AIモデル・新機能 | `AI model release new feature YYYY-MM-DD` | 3〜5件 |
| 🖥️ Big Tech発表 | `Apple Google Microsoft Windows announcement YYYY-MM-DD` | 3〜5件 |
| 📰 IT・DXニュース | `AI DX IT ニュース YYYY年M月D日` | 5件 |
| 𝕏 個人ポスト | `AI researcher engineer tweet YYYY-MM-DD` | 5件 |
| 🔬 注目論文 | `AI research paper arxiv YYYY-MM-DD` | 1件 |
 
### 市場指標の収集方法
 
**株式・VIX：**
- S&P500：終値、前日比（pt・%）
- 日経平均：終値、前日比（円・%）
- VIX（恐怖指数）：終値、前日比（上昇は市場不安の高まりを示す）
 
**債券：**
- 米10年債利回り：終値（%）、前日比（bps）
 
**為替：**
- ドル円：終値（円）
 
市場が閉まっていた場合（土日・祝日）はその旨を明記する。
 
### 景気指標の収集方法
 
前日に発表があった経済指標のみ記載する（なければ省略）：
- **米GDP**：速報値・改定値・確定値、前期比年率
- **米CPI / PCE**：前年比・前月比、コア指数
- **雇用統計**：非農業部門雇用者数、失業率、平均時給
- **PMI（製造業・サービス業）**：数値と前月比
- **その他**：小売売上高、住宅指標など
 
### 地政学リスクの収集方法
 
前日に動きがあった地政学イベントを3件まで：
- 戦争・紛争の動向
- 主要国の選挙・政治動向
- 外交・制裁・貿易摩擦
- テロ・サイバー攻撃など安全保障上のリスク

## Step 3: HTMLファイルの生成
 
`/mnt/user-data/outputs/ai-news-YYYY-MM-DD.md` に保存し `present_files` で提示する。
 
### タブ構成（9タブ）
 
1. **📈 市場指標** — 株・VIX・債券・為替の数値カード＋市場概況
2. **📊 景気指標** — GDP・CPI・雇用統計など（前日発表分のみ）
3. **🌏 地政学リスク** — 前日の主要地政学イベント
4. **🤖 AIモデル** — 前日発表のAIモデル・新機能
5. **🖥️ Big Tech** — Apple/Google/Microsoft の発表
6. **📰 IT・DX** — IT・AI・DXニュース5件
7. **𝕏 個人ポスト** — 個人研究者・エンジニアのX投稿5件
8. **🔬 論文** — 注目論文1件
9. **🧠 投資家視点** — バフェット視点・広瀬隆雄視点の2セクション
 
### デザイン仕様
 
- タブナビゲーションで9カテゴリを切り替え可能
- 市場指標は大きな数値カードで視認性を重視（VIXは赤系カラーで強調）
- 景気指標・地政学は発表がない日は「前日は主要発表なし」と明記
- カード型レイアウト、カテゴリ別にアクセントカラーを変える
- 投資家視点タブは2カラムレイアウト（バフェット左・広瀬右）
- 落ち着いたダークネイビー系ヘッダー
 
### カードの構成要素（AIモデル・ニュース系）
 
```
タイトル
発表元／著者 | 日付
本文（要約 2〜3文）
▶️ 今後の動向｜展望テキスト
🔗 ソースリンク
```
 
### 投資家視点の記述ルール

短期と中長期に分けて以下のルールに従うこと
 
**バフェット視点（🏦）：**
- バフェットの投資哲学：長期・割安・優良企業・安全余裕・シンプル・反投機
- 市場全体の動向・景気指標・地政学リスクを踏まえた長期的な解釈を記述
- 「バフェットならこう見るだろう」という形で200〜300字程度で記述
- キーワード：Margin of Safety、Mr.Market、長期保有、内在価値、割安バーゲン
 
**広瀬隆雄視点（📡）：**
- 広瀬隆雄のスタイル：マクロ分析・セクターローテーション・景気サイクル重視・米国市場中心
- 景気指標・金利・地政学・セクター動向を踏まえた実践的な相場観を記述
- 「広瀬隆雄ならこう分析するだろう」という形で200〜300字程度で記述
- キーワード：景気サイクル、FRB政策、セクターローテーション、リスクオン/オフ

## 品質チェックリスト
 
- [ ] すべての情報が**前日分**に限定されている
- [ ] 市場指標4項目（S&P500・日経・VIX・米10年債）がすべて含まれている
- [ ] 景気指標は前日発表があった場合のみ記載（なければ省略）
- [ ] 地政学リスクが3件以内で記載されている
- [ ] バフェット・広瀬視点がともに推量形（「〜だろう」「〜と見るだろう」）で記述されている
- [ ] Twitter欄は個人アカウントのみ（企業・組織公式除外）
- [ ] HTMLのタブ切り替えが正常に動作する
- [ ] 投資家視点の免責注記がSlack通知末尾にある
 
---
 
## 個人ポスト（𝕏）のルール
 
- 企業・組織・メディアの公式アカウント（@OpenAI, @Google, @AnthropicAI 等）は**除外**
- 個人名・個人ハンドルが判別できるアカウントのみ
- 個人の見解・発見・実験報告・考察を優先
 
---
 
## エラー対応
 
| 状況 | 対応 |
|------|------|
| 市場指標が取得できない | 「取得不可（土日・祝日の可能性あり）」と明記 |
| 景気指標の発表がない | 景気指標セクションをSlack通知から省略する |
| 地政学リスクに動きなし | 「前日は主要な地政学的動きなし」と1行記載 |
| Slack通知が5000字超 | 各項目をさらに短縮するかカテゴリ数を減らす |
| 検索結果が少ない | クエリを変えて再検索する |
 
---
 
## 使用ツール
 
- `web_search` — ニュース・論文・経済指標の収集
- `web_fetch` — 記事の詳細取得（必要に応じて）
- `create_file` — HTMLファイルの生成（`/mnt/user-data/outputs/`）
- `present_files` — HTMLファイルの提示
- `Slack:slack_send_message` — 要約版テキスト通知の送信
 
---
 
## カスタマイズ対応
 
- **チャンネル指定**：「#general に送って」→ そのチャンネルを使う
- **日付指定**：「一昨日のニュースで」→ 指定日を使う（デフォルトは前日）
- **テーマ絞り込み**：「AI規制に関するニュースだけ」→ 検索クエリを調整
- **言語**：デフォルトは日本語
