# ユーティリティ

ここには、生成AI（Claude, ChatGPT, Gemini等）との対話を通じて作成した**HTMLユーティリティ群**をアーカイブしています。

単なる「便利なツール」の配布だけでなく、**「どのようなプロンプト（指示）でこのコードが生まれたのか」**というプロセスを併記することで、AIエンジニアリングの試行錯誤を記録することを目的としています。

---

## 🛠️ コンセプト
- **No-Build / Simple**: 基本的に1つのHTMLファイルで完結し、ブラウザですぐに動くもの。
- **Prompt First**: 完璧なコードを目指すだけでなく、AIをどう導いたかの「レシピ」を大切にする。
- **Iterative**: AIとのラリーで機能を追加・修正していく過程を楽しむ。

> [!TIP]
> 各ツールのソースコード内のコメント、または詳細ページには、実際に使用したプロンプトを全文掲載しています。「もっとこうしたい」という場合は、そのプロンプトをベースにAIへさらなる指示を出してみてください。
